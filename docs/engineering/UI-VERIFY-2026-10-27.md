# 验证记录（2026-10-27）

环境：proot Ubuntu 24.04（workspace 63d0a510，**aarch64**），JDK 17.0.20.1，Gradle 9.5.0（wrapper 缓存），Kotlin 2.4.10，Android SDK `/opt/android-sdk`（platforms android-37.0 / build-tools 36.0.0 + 37.0.0）。无可用设备/模拟器。

## 一、Gradle 构建：跑了，失败，原因是环境而非改动

```
cd /workspace/wt-ui
ANDROID_HOME=/opt/android-sdk ./gradlew :app:compileMoxwDebugKotlin --no-daemon
→ BUILD FAILED in 24m 11s（96 tasks: 40 executed, 52 from cache）
```

三处失败，逐一确认与本次改动无关：

| 失败任务 | 报错 | 判定 |
|---|---|---|
| `:app:compileMoxwDebugAidl` | `A problem occurred starting process 'command /opt/android-sdk/build-tools/36.0.0/aidl'`；直接执行该文件报 `cannot execute: required file not found` | **根因**：SDK 里的 `aidl`/`aapt2` 是 x86-64 ELF（`e_machine=0x3e`），而 rootfs 是 aarch64，且没有 qemu-user。所有 Android SDK 二进制都跑不起来 → 资源/编译任务在本机不可能完成 |
| `:material3:compileDebugKotlin` | `Unresolved reference 'dynamiccolor'` | 根因：`material3/material-color-utilities` 是 git submodule，worktree 里没初始化。**已修复**：`git submodule update --init material3/material-color-utilities`（未初始化 llama.cpp，它只影响原生库） |
| `:web:buildWebUi` | `pnpm` exit 1，拉 `registry.npmjs.org` 的 mermaid/cytoscape 包 TLS 中断 | 网络环境问题（npm 源不稳），与改动无关 |

结论：**本机无法产出 APK，也无法完成 `:app` 的 Kotlin 类型检查**（类型检查排在 `processResources` 之后，而 aapt2 跑不了）。这一点不掩饰。

## 四、给下一次的接手说明

- 在有 x86-64（或带 qemu）的机器上，先 `git submodule update --init`（material3 必需，llama.cpp 仅原生），再 `./gradlew :app:testMoxwDebugUnitTest --tests '*MissionDescriptionCollapseTest*'` 与 `:app:assembleMoxwDebug`，就能补上本机缺的两项验证。
- `/opt/android-sdk/ndk/28.2.13676358` 是本机放的**占位目录**（只有 source.properties），只为让 `:llama-cpp` 过配置阶段；真实构建前应换成真 NDK 或删掉。
- 本机 `~/.gradle/init.gradle.kts` 已把仓库指向 aliyun 镜像（dl.google.com 不可达）。
