# 手感（Feel）—— 浮层 / 行 / 过渡的第三轮（2026-10-28）

分支 `arena/8e1fe44e-rikkahub-agent-pure`，基线 `4b17f70`。
前两轮（`UI-VISUAL-2026-10-27.md`、`UI-INK-2026-10-28.md`）动的是**皮**：主题、字阶、圆角、间距、输入条。
这一轮动的是**同一套语言**：每一个浮层、每一行、每一次过渡，都从同一个地方取值。

---

## 0. 一句话方向

**一层壳、一条曲线、一套行。**

| | 之前 | 现在 |
|---|---|---|
| 浮层 | 34 个 `ModalBottomSheet` 各写各的：圆角靠默认、面色靠默认、标题硬写一列、把手有的有有的没有 | 全部换成 `MoxwSheet`：形状 / 面色 / 遮罩 / 把手 / 标题一处定义 |
| 行 | 设置行是裸图标 + 文字，看不出哪些行能进 | `SettingIcon` 图标块 + 按组着色 + 自动箭头 |
| 过渡 | 页面切换是 spring 弹性 + 0.7 缩放；输入条 / 顶栏各自一条曲线 | 全应用一条 `Motion` 刻度，页面切换改成「推」 |

理由很简单：**用户感知到的「精致」不是来自某一个控件，而是来自「所有同类的东西长得一样」。**
上一轮把皮换齐了，这一轮把「行为一致」也换齐——两轮叠起来才是完整的一套。

---

## 1. 浮层：一个壳（`ui/components/ui/MoxwSheet.kt`，新文件）

之前 App 里有 **34 处** `ModalBottomSheet`，每一处的形状、面色、遮罩强度、拖拽把手、标题排版都是各写各的：
「模型选择」和「思考深度」两个弹层，从聊天页的输入条点进去像是跳到了另一个产品。

现在新增一个壳，四十来处弹层全部换用：

| 部件 | 取值 | 为什么 |
|---|---|---|
| 形状 | 上角 `Radius.sheet`（28dp），下角贴屏底 | 比卡片大一档，肉眼能看出「浮在内容之上」 |
| 面色 | `surfaceContainerLow` | 比 `background` 高半档：浮起来，但不刺眼 |
| 遮罩 | `scrim` 32% | 深浅主题同一强度；弹层永远是「压住」内容的 |
| 把手 | 36×4dp 圆角短条，32% 不透明度 | 是「提示」不是「控件」——用户不需要点它 |
| 标题 | `MoxwSheetHeader`：titleMedium + bodySmall，左对齐，24dp 起边距 | 之前每个弹层都硬写 `titleLarge`，标题和第一条内容之间没有任何分隔 |

配套：

- `MoxwSheetRow` —— 选择器类弹层里的一行（标题 / 副标题 / 选中态 / 前后缀）。
  选中态用 `primaryContainer` **铺底**而不是换图标颜色：深色主题里换颜色几乎看不出来。
- `MoxwSheetHandle` / `MoxwSheetDivider` / `MoxwSheetPadding` / `MoxwSheetItemSpacing`。

### 1.1 换壳的清单

- 聊天侧：助手选择、思考深度、搜索（含搜索服务二级页）、附件、MCP、工作区目录、聊天附件面板。
- 抽屉侧：移动到助手 / 移动到文件夹。
- 配置侧：主题编辑、子智能体编辑、提示词 / 设定集编辑、MCP 导入、技能目录 / 技能测试、
  工作台「创建任务」、图片 / 视频生成、模型列表、日志、分享、备份、SSH、提供商详情、TTS / ASR 等。

其中标题原本是弹层内容里手写的一段 `Text` 的（工作区、主题编辑、子智能体、提示词、MCP 导入、
技能目录、技能测试、创建任务），一并提到壳的 `title` 参数上；关闭按钮改用 `trailing` 槽位。

### 1.2 保留原行为的两个口子

- `dragHandle`：默认是统一把手；传 `null` 关掉（复制消息面板这种自带标题的）。
- `sheetGesturesEnabled`：内容本身可滚动的弹层（编辑器、工具详情）继续关掉下滑关闭，
  否则下滑会被误判成「关掉弹层」。

## 2. 行：设置页与配置页（`CardGroup` + 新增 `SettingIcon`）

`CardGroup` 全 App 有 **61 处**调用，所以改它等于同时改了所有设置页与配置页。

### 2.1 自动箭头

- 可点的行默认在末尾带一个 16dp 的 `ArrowRight01`（`onSurfaceVariant` 60%）。
  之前「这一行能进到下一级」只有字重和涟漪在暗示，一屏二十行里看不出来。
- 尾部已经有内容（开关、数值、按钮）的行不受影响。
- 点了之后**不是**进入下一级的行（设置首页的「分享」调起系统面板）显式 `chevron = false`。
- 助手详情页原本每行手写了一个 24dp 的箭头，现在由壳统一提供，那 7 处手写箭头删掉。

### 2.2 图标块（新增 `SettingIcon`）

设置页之前是 31 个裸 `Icon` 站在 56dp 高的行里，视觉重量太轻，整页只有一种颜色。

- 34dp 的浅色圆角块（10dp 圆角）+ 12% 透明度底 + 主色图标。
- 设置首页按「分组」分配色相：外观=陶土（tertiary）、模型=青瓷（primary）、助手/实例/数据=secondary、
  设备/关于=tertiary。于是四组在扫读时能靠色相分开，而不用读标题。
- 同样套用到助手详情页（8 行）与扩展页（3 行）。

## 3. 过渡：一条曲线（`ui/theme/Motion.kt` + `RouteActivity`）

### 3.1 刻度

`Motion` 原本只有 enter / emphasis / exit 三档，本轮补了：

- `Motion.grow()` / `Motion.shrink()`：容器长高 / 变矮，与 `emphasis` 同曲线。
- `Modifier.motionContentSize()`：`animateContentSize` 默认的 spring 会和旁边的圆角动画各走各的，
  改成同一条曲线后，高度与圆角才是同一次运动的两半。

### 3.2 页面切换（`RouteActivity.kt`）

之前是 M3 默认的 **spring 弹性 + 0.7 缩放**：页面从右边进来时底下那页被捏到 70%，
整屏跟着缩一下，读起来是「弹」而不是「推」，收尾还有一段回弹，和界面里其它动效不同调。

现在：

| | 之前 | 现在 |
|---|---|---|
| 前进 | spring + 缩到 0.7 | `Motion.emphasis()`（240ms，标准曲线）+ 缩到 **0.94** + 位移 1/4 |
| 返回 | spring + 缩放 0.7 | 与前进互为镜像，同样 240ms |
| 预测返回 | 同返回 | 同返回（手势松手后不再补一段动画） |
| 会话页 | 默认 fade | 走同一套 fade 刻度（主场景不做位移） |

### 3.3 聊天页内部

- 顶栏随滚动收起：200ms `FastOutSlowIn` → `Motion.emphasis()`。
- 输入条圆角 240ms、展开进度 220ms、发送圆盘 200ms → 全部 `Motion.emphasis()`。
- **消息快速跳转条**：之前是四个各自独立的浮动圆钮，贴着屏幕右缘排开，圆与圆之间没有共同的底，
  看起来像四个不小心飘在那里的按钮；出现时又从屏幕外横着滑进来（位移是自身宽度的两倍），
  在正文上划一道。现在收成一条竖直导轨：一个半透明圆角容器 + 发丝线分组，
  进出走淡入 + 轻微缩放，「回到底部」用主色标出（它是这四个里唯一九成时候会被按到的动作）。
  滚动动画也统一到 `Motion.emphasis()`。

## 4. web-ui（同一套刻度，同步落地）

- 新增 `app/lib/motion.ts`（与 `Motion.kt` 同一套刻度）+ `app.css` 的 `--motion-*` 变量。
- `sheet.tsx`：面板从 `bg-background`（与页面同色，像「页面被挖掉一块」）改成 `bg-card`
  + 1px 描边；底部抽屉上角 28px（与 Android 端 `Radius.sheet` 同档）+ 拖拽把手；
  进场 240ms / 出场 120ms，遮罩 160ms / 120ms。
- `dialog.tsx`：同一套壳（`bg-card` + 描边 + 缩放 96%）。
- `sidebar.tsx`（移动端抽屉）、`chat-input.tsx`、`conversations.tsx`、`chain-of-thought.tsx`：
  残留的 `duration-200 / ease-out` 全部换成 motion 变量。

校验：`npm run typecheck`、`npm run build` 均通过（产物仍按 `copy.ts` 拷进 `web/src/main/resources/static`）。

   还是各自一套展开动画，可以再收一档。

   可以写一个 JVM 测试，扫源码里残留的 `tween(...)` / `spring(...)` 字面量。
